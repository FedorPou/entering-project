Шаг между центрами выводов (Pitch): ровно 7.2 мм.

Диаметр отверстия (Hole Size / Drill): 2.8 мм.

Диаметр контактной площадки (Pad Size): 4.5 — 5.0 мм (лучше сделать побольше, чтобы было за что зацепиться припою).

Дополнительные крепежные отверстия (только для угловой XT60-PW): обычно по бокам есть два пластиковых штырька для фиксации. Расстояние между ними 14.2 мм, диаметр отверстий под них — 2.5 мм (эти отверстия делаются без металлизации).
